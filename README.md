
# 🎬 Netflix Clone Website

## 📌 About the Project

This project is a Netflix-inspired streaming website interface
created for educational purposes.

The website provides a movie browsing experience with a
dark theme, movie sections, navigation links, and a
responsive layout inspired by streaming platforms.

## 🎯 Objectives

- Learn HTML and CSS through a practical project.
- Design a streaming platform homepage.
- Display movies and TV shows using cards.
- Create a modern and attractive user interface.
- Practice responsive web design.
- Understand website layout and styling.

## 🛠️ Technologies Used

- HTML5 - Used to create the structure of the website.
- CSS3 - Used for styling, layouts, colors, and animations.

## 📂 Project Structure

Netflix-Clone/
│
├── index.html
├── style.css
└── README.md

## ✨ Features

- Netflix-inspired dark theme.
- Navigation bar with website links.
- Hero section featuring a highlighted title.
- Movie and TV show cards.
- Movie categories and content sections.
- Hover effects on movie cards and buttons.
- Responsive layout for different screen sizes.
- Attractive background images.
- Simple and user-friendly design.

## ▶️ How to Run the Project

1. Download or copy the project files.
2. Open the project folder in Visual Studio Code.
3. Make sure index.html and style.css are in the same folder.
4. Open index.html in your web browser.
5. Alternatively, use the Live Server extension in VS Code.
6. Keep your internet connection active if the website uses
   online images.

## 💻 Technologies Explained

### HTML5

HTML creates the webpage structure, including headings,
navigation links, movie cards, buttons, and sections.

### CSS3

CSS controls the website's colors, fonts, spacing,
backgrounds, hover effects, and responsive layout.
